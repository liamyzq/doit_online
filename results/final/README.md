# Published final results

This directory contains copies of the final aggregate analyses and the image
evidence linked from [the findings report](../../docs/findings.md). Original
filenames and paths below the local `artifacts/` directory are preserved here.
The images and JSON contents are unchanged.

- `exp-032-combined-summary.json`: all eight final groups, 512 images in total,
  compared with moderate MC8.
- `exp-031-vs-mc32.json`: the seven exp-031 groups compared with MC32.
- The experiment subdirectories contain six original PNGs showing the paired
  lighthouse and cafe comparisons discussed in the report.
- The two lighthouse comparison sheets show the eight reserved lighthouse
  seeds used for the qualitative review.

The summaries retain the original local `artifacts/` source-run paths. The full
run artifacts, embeddings, and tensor banks remain on Orion at
`/home/mlw0719/doit_correction_storage/runs/`. This published subset supports
reading the final conclusions online; use the full artifacts and
[reproduction guide](../../docs/reproduction.md) to recompute the analyses.
